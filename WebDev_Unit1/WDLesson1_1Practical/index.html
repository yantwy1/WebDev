Web Technologies

HTML

HTML Stands for Hyper Text Markup Language, it is the standard code to structure and display content on the internet.

CSS

CSS stands for Cascading Style Sheets, and it is the standard style sheet language used to define the visual presentation, layout, and design of web pages. Alongside HTML (which provides the structure) and JavaScript (which adds interactivity), CSS is one of the three cornerstone technologies of the World Wide Web.

JavaScript

JavaScript (JS) is a versatile, high-level programming language that serves as one of the core technologies of the World Wide Web, alongside HTML and CSS. While HTML structures web content and CSS styles its appearance, JavaScript makes web pages interactive and dynamic, it is supported by all major web browsers and powers over 98% of all websites globally.

Java

Java is a popular, high-level programming language and computing platform created in 1995 that allows developers to write code once and run it on any device.
